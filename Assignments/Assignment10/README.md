1. The topic of my database is sets in the card game Magic: The Gathering.
The purpose of my program is to create a database of the sets of cards in MTG,
and give the user a method to answer some questions about the data set
without needing to write queries on the data. My API can answer questions like
"How many sets were released in each year?", "What is the order of the sets
if order them based on another column?", "Which sets meet criteria XYZ?",
"How many sets are there of each type?", and "How many cards are there
per set on average?"
